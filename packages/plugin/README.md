# @heretek-ai/godot-opencode

Godot Engine OpenCode v2 native plugin — zero-Python transport, dual-mode
verification, studio swarm, and vision (Bun/TypeScript), plus the `companion/`
GDScript editor addon.

- Install: `bun add @heretek-ai/godot-opencode` (or `npm i @heretek-ai/godot-opencode`)
- Docs: `docs/INSTALL.md`, `docs/API.md`, `docs/ARCHITECTURE.md`, `docs/RELEASE-1.0.0.md`
- Companion addon: `companion/addons/godot_opencode/` (Godot 4.x editor, loopback 127.0.0.1:9500)
